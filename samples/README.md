# Optional sample cues

These files were generated from actual runs of the included synthetic examples.
Nothing plays automatically. Each folder contains a text transcript, one WAV
per completed stage, and an overview WAV. The failed example includes a dedicated
error cue after the failing stage. Earlier successful outputs remain in its
transcript; successful peers in the failed group are described as unpublished.

The sound is a summary, not measured execution timing. Every exact operation,
input, result, and error is available as text. Device listening quality and
screen-reader interaction have not been evaluated.
